Repositório dedicado aos exercícios da disciplina de Linguagens de Programação (26.4 - Modular).
O projeto foi organizado de modo que cada ciclo é um módulo.

## Estrutura

```
ciclo2/
└── src/
    └── ciclo2/
        ├── q1_idade.py
        ├── q2_triangulo.py
        ├── q3_menor_num.py
        ├── q4_primo.py
        └── q5_letras_invertidas.py
```

## Como executar

A partir da raiz do repositório:

```bash
python ciclo2/src/ciclo2/q1_idade.py
```

Troque o nome do arquivo para executar os demais.
